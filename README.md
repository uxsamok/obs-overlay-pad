# OBS Overlay Pad (v1)

PWA-пульт для планшета: сетка ячеек включает/выключает оверлеи в OBS Studio через obs-websocket v5. Без сборки и бэкенда — чистые HTML/CSS/JS.

## Запуск
1. На машине с OBS скопируйте папку и запустите в ней:
   ```
   python3 -m http.server 8080
   ```
2. На планшете откройте `http://IP-машины-OBS:8080` (IP: `ipconfig` / `ip a`). Разрешите порт 8080 в брандмауэре.

## Chrome на Android (установка и офлайн)
1. Откройте `chrome://flags/#unsafely-treat-insecure-origin-as-secure`.
2. Впишите `http://IP-машины-OBS:8080`, включите **Enabled**, нажмите **Relaunch**.
3. Откройте приложение → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

## Настройка OBS
- **WebSocket**: Инструменты → Настройки сервера WebSocket → включить, порт 4455, задать пароль. Этот же хост/порт/пароль — в настройках приложения.
- **Переходы**: правый клик по источнику в сцене → «Переход показа» / «Переход скрытия» (Fade, Slide, Swipe…). Приложение только включает/выключает видимость, анимацию проигрывает OBS. Поле «Out, с» — длительность перехода скрытия (для справки и будущих цепочек).
- **Сцена с оверлеями**: положите оверлеи во вложенную сцену (напр. `Overlays`) и добавьте её в игровые сцены. Кнопка «Скрыть всё» переключает видимость этой вложенной сцены в текущей программной сцене.
- Источники ищутся по имени во всех сценах (и группах). Имена должны быть уникальны — иначе на ячейке «⚠ дубль имени».
- **Replay Buffer**: Настройки → Вывод → Буфер повтора → «Максимальное время повтора» (напр. 60 с). Запустите буфер («Начать буфер повтора»). Создайте Media Source (напр. `Replay`) — его имя укажите в настройках приложения; ячейка типа «Последний повтор» подставит в него последний файл и покажет.
- **Таймер игры**: текстовый источник (Text GDI+/FreeType), имя — в настройках. Ячейки с галочкой «Таймер игры» перезапускают его. Тап по таймеру в шапке — остановить.

## Ячейки
- **Оверлей** — режим «По таймеру» (показать на N секунд, обратный отсчёт на ячейке) или «Переключатель» (тап — вкл., тап — выкл.). Перед показом источник делается невидимым, затем видимым.
- **Счётчик** — левая половина ячейки −1, правая +1; пишет текст по шаблону (`Матч {n}`) в текстовый источник.
- **Последний повтор** — см. Replay Buffer.
- Галочка **Таймкод** — при нажатии записывает время от начала стрима (или записи, если стрим не идёт) и текст ячейки.

Прокрутка: короткий тап активирует, сдвиг пальца ≥10px — только прокрутка. Справа — номера страниц.

## Таймкоды
Шапка → «Таймкоды»: список по стримам (новый создаётся автоматически при старте стрима), метки можно переименовать/удалить, «Скопировать для YouTube» даёт текст с `00:00 Начало`. Кнопка «★ Момент» ставит метку «Момент N».

## Резервная копия
Настройки → «Сохранить JSON» / «Загрузить JSON» (все настройки, ячейки и таймкоды). Данные хранятся в localStorage планшета.

## Архитектура
- `js/obs.js` — клиент obs-websocket v5 (авторизация SHA-256, автопереподключение, `broadcast()` для BroadcastCustomEvent).
- `js/actions.js` — слой действий (show/hide, текст, повтор, статус). v2: локальные Browser Source страницы, управляемые через BroadcastCustomEvent.
- `js/store.js` — состояние/JSON; `js/app.js` — UI; `sw.js` — офлайн-кэш (network-first).
