# OBS Overlay Pad (v1)

PWA-пульт для планшета: сетка ячеек включает/выключает оверлеи в OBS Studio через obs-websocket v5. Без сборки и бэкенда — чистые HTML/CSS/JS.

## Запуск
**Windows (рекомендуется):** готовый сервер с автозапуском и ручным обновлением — см. [server/windows/README.md](server/windows/README.md).

Быстрый вариант для проверки:
1. На машине с OBS скопируйте папку и запустите в ней:
   ```
   python3 -m http.server 5757
   ```
2. На планшете откройте `http://IP-машины-OBS:5757` (IP: `ipconfig` / `ip a`). Разрешите порт 5757 в брандмауэре.

## Chrome на Android (установка и офлайн)
1. Откройте `chrome://flags/#unsafely-treat-insecure-origin-as-secure`.
2. Впишите `http://IP-машины-OBS:5757`, включите **Enabled**, нажмите **Relaunch**.
3. Откройте приложение → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

## Настройка OBS
- **WebSocket**: Инструменты → Настройки сервера WebSocket → включить, порт 4455, задать пароль. Этот же хост/порт/пароль — в настройках приложения.
- **Переходы**: правый клик по источнику в сцене → «Переход показа» / «Переход скрытия» (Fade, Slide, Swipe…). Приложение только включает/выключает видимость, анимацию проигрывает OBS.
- **Сцена с оверлеями**: положите оверлеи во вложенную сцену (напр. `Overlays`) и добавьте её в игровые сцены. Кнопка «Скрыть всё» переключает видимость этой вложенной сцены в текущей программной сцене.
- Источники ищутся по имени во всех сценах (и группах). Имена должны быть уникальны — иначе на ячейке «⚠ дубль имени».
- **Повтор (Replay Buffer)** — пошагово (то же написано в приложении: Настройки → Повтор):
  1. OBS: Настройки → Вывод → Буфер повтора → включить, «Максимальное время повтора» 30 с.
  2. Добавьте в сцену источник «Медиа» (Media Source), напр. `Replay`, снимите в нём «Зациклить» (Loop), скройте его.
  3. Впишите его имя в Настройки → Повтор.
  4. Перед стримом — кнопка **● Буфер** в шапке (зелёная = буфер пишет).
  5. Момент → **⟲ Сохранить повтор** → **▶ Показать повтор**. Видео скрывается само по окончании или повторным нажатием (и останавливается). Ячейка «Последний повтор» делает то же, при желании с таймером.
- **Таймер игры**: текстовый источник (Text GDI+/FreeType), имя — в настройках. В Настройки → Таймер игры отметьте ячейки, которые перезапускают таймер. Тап по таймеру в шапке — остановить.

## Шапка
- Слева статусы: связь с OBS, **ЭФИР** (мигает, если OBS на связи, а эфира нет), **REC** (запись), время эфира, таймер игры, часы.
- Крупные кнопки для эфира: ★ Момент, ⟲ Сохранить повтор, ▶ Показать повтор, 🎤 Мик (красная = микрофон выключен; источник — Настройки → Микрофон).
- Мелкие, отдельно: ● Буфер, Скрыть всё, Таймкоды, ⚙.

## Ячейки
- Цвет ячейки: палитра или код `#RRGGBB`. Пустая/нулевая длительность = 8 с.
- **Оверлей** — режим «По таймеру» (показать на N секунд, обратный отсчёт на ячейке) или «Переключатель» (тап — вкл., тап — выкл.). Перед показом источник делается невидимым, затем видимым.
- **Счётчик** — кнопки − / + на ячейке (значение можно поправить и в настройках); пишет текст по шаблону (`Матч {n}`) в текстовый источник.
- **Последний повтор** — см. Replay Buffer.
- Галочка **Таймкод** — при нажатии записывает время от начала стрима (или записи, если стрим не идёт) и текст ячейки.

Порядок ячеек: кнопка ⇅ справа внизу включает режим перестановки — перетащите ячейку на новое место, ⇅ ещё раз — выход.

Прокрутка: короткий тап активирует, сдвиг пальца ≥10px — только прокрутка. Справа — номера страниц.

## Таймкоды
Шапка → «Таймкоды»: список по стримам (новый создаётся автоматически при старте стрима), метки можно переименовать/удалить, «Скопировать для YouTube» даёт текст с `00:00 Начало`. Кнопка «★ Момент» ставит метку «Момент N».

## Резервная копия
Настройки → «Сохранить JSON» / «Загрузить JSON» (все настройки, ячейки и таймкоды). Данные хранятся в localStorage планшета.

## Архитектура
- `js/obs.js` — клиент obs-websocket v5 (авторизация SHA-256, автопереподключение, `broadcast()` для BroadcastCustomEvent).
- `js/actions.js` — слой действий (show/hide, текст, повтор, статус). v2: локальные Browser Source страницы, управляемые через BroadcastCustomEvent.
- `js/store.js` — состояние/JSON; `js/app.js` — UI; `sw.js` — офлайн-кэш (network-first).
