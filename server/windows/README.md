# Сервер для планшета на Windows (Caddy)

## Что это и зачем
Планшету нужно откуда-то открыть страницу приложения, чтобы установить его как PWA.
Этот набор скриптов превращает компьютер с OBS в маленький веб-сервер:

- **Caddy** (`caddy.exe`, один файл без установки) раздаёт папку `app\` рядом со скриптами по адресу `http://IP-компьютера:8080`.
- **Планировщик заданий Windows** запускает Caddy при старте Windows (от SYSTEM, без окна, даже без входа в систему) и перезапускает при сбое.
- **Правило брандмауэра** открывает порт 8080 только для «Частной» сети.
- **Обновления — только вручную**: `update.bat`. Сам ничего из интернета не качает.

**Почему HTTP, а не HTTPS.** Приложение подключается к OBS по `ws://` (obs-websocket без шифрования). Страница, открытая по `https://`, не может подключаться к `ws://` — браузер заблокирует. Поэтому в `Caddyfile` HTTPS выключен (`auto_https off`).

**Почему Caddy.** Один exe, конфиг на 10 строк, ничего не надо устанавливать (в отличие от IIS/nginx/Docker/Python).

## Что где лежит
Набор работает из **любой папки**: всё, что он создаёт, лежит в ней же. Папка = одна установка.
```
<папка>\
  config.ps1       НАСТРОЙКИ (порт). Единственное, что обычно правят
  common.ps1       общие пути и функции (всё вычисляется от этой папки)
  install.bat      установка / переустановка (повторный запуск безопасен)
  update.bat       обновить приложение с GitHub
  rollback.bat     вернуть предыдущую версию
  status.bat       проверить, всё ли работает
  restart.bat      перезапустить сервер
  uninstall.bat    убрать автозапуск и правило брандмауэра
  --- появляется после установки ---
  caddy.exe        сервер
  Caddyfile        настройки сервера (создаётся install из config.ps1, руками не править)
  app\             файлы приложения, которые видит планшет
  app.bak\         предыдущая версия (для отката)
  logs\caddy.log   журнал сервера
```
`.bat` — просто обёртки, вся логика в одноимённых `.ps1`. Двойной клик; права администратора `.bat` попросит сам.

## Установка
1. Скачайте репозиторий: https://github.com/uxsamok/obs-overlay-pad → Code → Download ZIP.
2. Скопируйте из него папку `server\windows` куда угодно, например `C:\obs-overlay-pad` (лучше не в «Загрузки» и не на рабочий стол — чтобы случайно не удалить). Сам ZIP потом не нужен.
3. Дважды кликните `install.bat` в этой папке, согласитесь на права администратора.
4. Скрипт скачает Caddy и приложение в эту папку, настроит автозапуск (задача «OBS Overlay Pad (port 8080)») и брандмауэр и напечатает адреса вида `http://192.168.1.50:8080`.

Почему скрипты не скачивают сами себя: так проще — скрипты меняются редко, а приложение обновляется `update.bat`. Если когда-нибудь понадобятся новые скрипты — скопируйте свежую `server\windows` поверх старой папки (app\ и caddy.exe не затрутся) и запустите `install.bat`.

**Перенесли папку** → запустите `install.bat` в новом месте (задача перенастроится на новую папку).
**Сменить порт** → поменяйте `$Port` в `config.ps1`, запустите `install.bat`.
**Две установки рядом** (например, тестовая) → вторая копия папки с другим портом в `config.ps1`. Имена задачи и правила брандмауэра содержат порт, поэтому не пересекаются.

## Открыть на планшете (Chrome, Android)
1. Планшет и компьютер — в одной Wi-Fi/сети.
2. Для установки PWA и работы Service Worker Chrome требует «безопасный» адрес, а HTTP по IP таким не считается. Поэтому один раз:
   - откройте `chrome://flags/#unsafely-treat-insecure-origin-as-secure`;
   - впишите адрес, например `http://192.168.1.50:8080`, переключите на **Enabled**, нажмите **Relaunch**.
3. Откройте этот адрес → меню ⋮ → «Установить приложение».

Совет: закрепите IP компьютера (резервирование DHCP в роутере), иначе после смены IP придётся заново менять флаг и переустанавливать PWA.

## Обновление
1. Дважды кликните `update.bat` в папке установки.
   Скачается свежая версия ветки `main`; если в архиве нет `index.html`, текущая версия не трогается. Старая версия сохраняется в `app.bak`.
2. На планшете закройте приложение и откройте снова.

## Офлайн и как обновления доходят до планшета
- После **первого** открытия приложение целиком (страница, стили, скрипты, иконки) сохраняется на планшете и дальше **работает, даже если компьютер-сервер выключен** (нужен только OBS по сети).
- Каждый запрос сначала идёт на сервер; если сервер не ответил за ~2,5 с или недоступен — берётся сохранённая копия.
- Поэтому новая версия после `update.bat` подхватывается при следующем открытии приложения, когда сервер доступен (иногда нужно открыть дважды).
- Сервер отдаёт файлы с `Cache-Control: no-cache`, чтобы браузер не держал старые копии.
- Для разработчика: список сохраняемых файлов — `FILES` в `sw.js`; добавили файл — впишите его туда и увеличьте номер в `CACHE`.

Что-то сломалось после обновления → `rollback.bat`.

## Если не работает
1. `status.bat` — покажет задачу, процесс caddy, ответ сервера, правило брандмауэра, тип сети и адреса.
2. Локально открывается (`http://localhost:8080` на самом компьютере), а с планшета нет:
   - тип сети «Общедоступная» → Параметры → Сеть и Интернет → свойства подключения → **Частная**;
   - сторонний антивирус/брандмауэр блокирует порт 8080;
   - планшет в гостевой Wi-Fi (изолирована от компьютеров);
   - IP компьютера поменялся — смотрите `status.bat`.
3. Сервер не запущен → `restart.bat`, смотрите `logs\caddy.log`. Порт занят другой программой → другой `$Port` в `config.ps1`, затем `install.bat`.
4. Ручной запуск, чтобы увидеть ошибки Caddy: в папке установки выполнить
   `caddy.exe run --config Caddyfile --adapter caddyfile`.
5. Задачу можно посмотреть в «Планировщике заданий»: `OBS Overlay Pad (port 8080)`.
6. Папку перенесли/переименовали → `install.bat` в новом месте.

## Удаление
`uninstall.bat` — останавливает сервер, удаляет задачу и правило брандмауэра этой установки. Потом просто удалите папку.
На планшете: удалить приложение и (по желанию) выключить флаг в `chrome://flags`.
