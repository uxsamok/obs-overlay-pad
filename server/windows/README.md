# Сервер для планшета на Windows (Caddy)

## Что это и зачем
Планшету нужно откуда-то открыть страницу приложения, чтобы установить его как PWA.
Этот набор скриптов превращает компьютер с OBS в маленький веб-сервер:

- **Caddy** (`caddy.exe`, один файл без установки) раздаёт папку `C:\obs-overlay-pad\app` по адресу `http://IP-компьютера:8080`.
- **Планировщик заданий Windows** запускает Caddy при старте Windows (от SYSTEM, без окна, даже без входа в систему) и перезапускает при сбое.
- **Правило брандмауэра** открывает порт 8080 только для «Частной» сети.
- **Обновления — только вручную**: `update.bat`. Сам ничего из интернета не качает.

**Почему HTTP, а не HTTPS.** Приложение подключается к OBS по `ws://` (obs-websocket без шифрования). Страница, открытая по `https://`, не может подключаться к `ws://` — браузер заблокирует. Поэтому в `Caddyfile` HTTPS выключен (`auto_https off`).

**Почему Caddy.** Один exe, конфиг на 10 строк, ничего не надо устанавливать (в отличие от IIS/nginx/Docker/Python).

## Что где лежит (после установки)
```
C:\obs-overlay-pad\
  caddy.exe        сервер (скачивается install.bat)
  Caddyfile        настройки сервера
  app\             файлы приложения, которые видит планшет
  app.bak\         предыдущая версия (для отката)
  common.ps1       общие настройки: папка, порт, ссылки (менять здесь)
  install.bat      установка / переустановка
  update.bat       обновить приложение с GitHub
  rollback.bat     вернуть предыдущую версию
  status.bat       проверить, всё ли работает
  restart.bat      перезапустить сервер
  uninstall.bat    удалить
```
`.bat` — просто обёртки, вся логика в одноимённых `.ps1`. Двойной клик; права администратора `.bat` попросит сам.

## Установка
1. Скачайте репозиторий: https://github.com/uxsamok/obs-overlay-pad → Code → Download ZIP, распакуйте.
2. Откройте `server\windows` и дважды кликните `install.bat`, согласитесь на права администратора.
3. Скрипт скачает Caddy и приложение, настроит автозапуск и брандмауэр и напечатает адреса вида `http://192.168.1.50:8080`.
4. Распакованный ZIP после этого можно удалить — всё нужное уже в `C:\obs-overlay-pad`.

Повторный запуск `install.bat` безопасен (заодно обновляет Caddy).

## Открыть на планшете (Chrome, Android)
1. Планшет и компьютер — в одной Wi-Fi/сети.
2. Для установки PWA и работы Service Worker Chrome требует «безопасный» адрес, а HTTP по IP таким не считается. Поэтому один раз:
   - откройте `chrome://flags/#unsafely-treat-insecure-origin-as-secure`;
   - впишите адрес, например `http://192.168.1.50:8080`, переключите на **Enabled**, нажмите **Relaunch**.
3. Откройте этот адрес → меню ⋮ → «Установить приложение».

Совет: закрепите IP компьютера (резервирование DHCP в роутере), иначе после смены IP придётся заново менять флаг и переустанавливать PWA.

## Обновление
1. Дважды кликните `C:\obs-overlay-pad\update.bat`.
   Скачается свежая версия ветки `main`; если в архиве нет `index.html`, текущая версия не трогается. Старая версия сохраняется в `app.bak`.
2. На планшете закройте приложение и откройте снова.

Почему обновление доходит до планшета: сервер отдаёт все файлы с `Cache-Control: no-cache`, а `sw.js` работает по схеме «сначала сеть, потом кэш» — при доступном сервере всегда берётся свежий файл, кэш нужен только когда сервер недоступен.

Что-то сломалось после обновления → `rollback.bat`.

## Если не работает
1. `status.bat` — покажет задачу, процесс caddy, ответ сервера, правило брандмауэра, тип сети и адреса.
2. Локально открывается (`http://localhost:8080` на самом компьютере), а с планшета нет:
   - тип сети «Общедоступная» → Параметры → Сеть и Интернет → свойства подключения → **Частная**;
   - сторонний антивирус/брандмауэр блокирует порт 8080;
   - планшет в гостевой Wi-Fi (изолирована от компьютеров);
   - IP компьютера поменялся — смотрите `status.bat`.
3. Сервер не запущен → `restart.bat`. Порт 8080 занят другой программой → поменяйте `8080` в `Caddyfile` и `common.ps1`, затем `install.bat`.
4. Ручной запуск, чтобы увидеть ошибки Caddy: в `C:\obs-overlay-pad` выполнить
   `caddy.exe run --config Caddyfile --adapter caddyfile`.
5. Задачу можно посмотреть в «Планировщике заданий»: `OBS Overlay Pad (Caddy)`.

## Удаление
`uninstall.bat` — удаляет задачу и правило брандмауэра, останавливает caddy и спрашивает, удалить ли папку `C:\obs-overlay-pad`.
На планшете: удалить приложение и (по желанию) выключить флаг в `chrome://flags`.
